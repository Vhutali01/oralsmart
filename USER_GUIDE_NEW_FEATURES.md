# Quick Reference: New Features

## 🆕 What's New - Usability Improvements

### 1. 💡 Help Tooltips
**What:** Hover over the (ⓘ) icon next to field labels to see helpful tips.

**Where:**
- Patient creation form (Parent ID, Contact Number)
- Assessment forms (coming soon to more fields)

**How to use:**
1. Look for the (ⓘ) icon next to field labels
2. Hover your mouse over it
3. Read the helpful tip that appears

**Example:**
```
Parent ID: [_____________] (ⓘ)
           ↑
   Hover here to see: "Enter exactly 13 digits (e.g. 8001015009087)"
```

---

### 2. ✅ Better Error Messages
**What:** Clear, specific error messages that tell you exactly what to fix.

**Before:** "Please answer all required questions: sa_citizen, special_needs"
**Now:** "⚠️ Please complete all required questions. Missing: South African Citizen, Special Needs. Scroll through the form to find and answer these questions."

**Where:** All forms with validation

---

### 3. ⚠️ Confirmation Dialogs
**What:** Double-check before important actions.

**Where:**
- Sending email reports
- Submitting long assessment forms
- Any action you can't undo

**Example:**
```
[Send Email] ← Click this button
     ↓
"Are you sure you want to send this report to patient@email.com?"
[Cancel] [OK]
```

---

### 4. 💾 Save as Draft (NEW!)
**What:** Save your progress on long forms and finish later.

**Where:**
- Dental Screening form
- Dietary Screening form (coming soon)

**How to use:**
1. Fill out part of the assessment
2. Click the "Save as Draft" button
3. Return to patient list
4. Come back later to finish

**Benefits:**
- No need to complete forms in one sitting
- Take breaks without losing work
- Handle interruptions gracefully

**Visual:**
```
[💾 Save as Draft]  [✓ Complete Dental Screening]
      ↑                        ↑
  Saves & exits          Final submission
```

---

### 5. 🔍 Search Patients
**What:** Quickly find patients by name, ID, or contact.

**Where:** Patient List / Referrals page

**How to use:**
1. Type patient name, surname, ID, or contact number
2. Click Search or press Enter
3. Results update instantly
4. Click "Clear" or X to show all patients again

**Example:**
```
🔍 [Search patients by name, ID, or contact...] [Search]
```

---

## 📋 Format Reference

### South African ID Number
- **Format:** 13 digits
- **Example:** 8001015009087
- **No spaces or dashes**

### Contact Number
- **Format:** 10 digits
- **Example:** 0821234567
- **Starts with 0**
- **No spaces or dashes**

## 💡 Pro Tips

### Keyboard Shortcuts (Coming Soon)
- `Ctrl+S` - Save draft
- `Ctrl+Enter` - Submit form
- `Esc` - Cancel action

### Best Practices
1. **Use tooltips** - Don't guess formats, check the help icons
2. **Save drafts often** - For long forms, save every 10-15 minutes
3. **Read confirmations** - Double-check recipient emails before sending
4. **Use search** - Don't scroll through long lists, search instead
5. **Review errors carefully** - New error messages tell you exactly what to fix

### Time Savers
- Search patients instead of scrolling: **Saves 2-3 minutes**
- Use save as draft: **Saves 5-15 minutes** when interrupted
- Follow error message guidance: **Saves 1-2 minutes** per error

## 🆘 Having Trouble?

### Tooltips not showing?
- Make sure you're hovering directly over the (ⓘ) icon
- Wait 1 second for tooltip to appear
- Try refreshing the page

### Draft not saving?
- Check that you clicked "Save as Draft" button
- Look for the success message at the top
- Check patient list for draft indicator

### Search not working?
- Make sure you clicked the Search button or pressed Enter
- Try searching with fewer characters
- Check spelling of patient name

### Error messages confusing?
- Read the full message - it tells you exactly what's missing
- Scroll through the form to find the mentioned fields
- Look for red highlighting on fields
