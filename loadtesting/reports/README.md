# Load Testing Reports Directory

This directory contains load testing reports and results.

## Report Files

- `load_test_report.html` - Main HTML report with charts and graphs
- `load_test_stats_*.csv` - Raw statistics in CSV format
- `performance_analysis.md` - Performance analysis and recommendations

## Directory Structure

```
reports/
├── load_test_report.html      # Main HTML report
├── load_test_stats_stats.csv  # Response time stats
├── load_test_stats_failures.csv # Failure statistics  
└── performance_analysis.md    # Analysis and recommendations
```

Reports are automatically generated when running load tests with the HTML and CSV options enabled.
